III 설계IIIIV참고
디멘션이렇게 설계합니다
크기와 비율콘텐츠 길이와 조작 영역을 함께 설계합니다. 고정 높이로 긴 문구를 자르지 않습니다.
타이포그래피본문 · 레이블 · 제목의 역할을 나눕니다. 좁은 화면에서는 줄바꿈과 재배치를 먼저 합니다.
색과 대비블루는 행동과 선택, 네이비와 중립색은 정보 위계입니다. 상태는 색만으로 전하지 않습니다.
배치와 정렬DOM 읽기 순서와 보이는 순서를 맞춥니다. 표 · 다이어그램 스크롤은 그 영역에서 관리합니다.
간격과 그룹화레이블 · 컨트롤 · 도움말을 한 묶음으로 둡니다. 밀도는 글자 축소가 아니라 간격으로 표현합니다.
표면과 깊이표면 · 반경 · 경계 · 그림자의 역할을 나눕니다. 도킹 패널은 문서의 보조 영역입니다.
상호작용과 피드백로딩 · 빈 상태 · 오류 · 완료를 구분하고 복구 행동을 줍니다. 포커스와 선택 상태를 함께 유지합니다.

참고FAQ

자주 헷갈리는 다섯 가지

IIIIIIIV참고 FAQ·용어·출처
사이트에 ReUI · Base UI가 설치되어 있나요?

아닙니다. 현재 dependency에 없습니다. ReUI Base UI + Nova + Neutral은 소비 앱의 이관 후보(제안)입니다.

npm으로 바로 설치할 수 있나요?

klic-design@latest가 npm에 발행되어 있습니다. 하나의 패키지에서 Agent Skill · 토큰 · 테마 · CLI · 컴포넌트 · 블록 · 모션을 제공합니다.

A/B 높이나 PageTitle 24→30px는 기본값인가요?

아닙니다. 회귀 fixture와 산술 예시이며 제품 기본값으로 자동으로 올리지 않습니다.

Liquid Glass는 실제 유리처럼 굴절되나요?

tint · blur · rim을 쓴 CSS 광학 근사입니다. 실제 굴절이나 Figma GLASS와 같은 렌더링을 주장하지 않습니다.

문서와 단위 테스트가 있으면 접근성이 검증된 건가요?

아닙니다. 단위 테스트는 정적 계약의 증거입니다. 자동 탐지 결과 0건도 WCAG 적합성 판정이 아니며, 실제 보조기술 · 확대 · IME 시험이 따로 필요합니다.
